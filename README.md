# 🎮 Quiz Bezerros - Teste Seu Conhecimento sobre a Cidade

Um quiz interativo sobre a cidade de Bezerros (PE), desenvolvido com HTML, CSS e JavaScript.

![Preview do Projeto](https://github.com/user-attachments/assets/f21f51da-ec59-4bfa-add5-bb9c330f9988) 

## 🚀 Como Jogar

1. **Acesse o jogo online**: [Link do GitHub Pages](https://matheusmagno.github.io/Quiz-Bezerros/)
2. Responda as perguntas sobre cultura, história e curiosidades de Bezerros.
3. Veja sua pontuação final e compartilhe com amigos!
